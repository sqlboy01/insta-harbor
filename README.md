# Insta Harbor

Download photos, videos, Reels, carousels, Stories and individual Highlights from Instagram with organized profile folders.

[![Install from the Chrome Web Store](https://img.shields.io/badge/Install-Chrome%20Web%20Store-2489f5?style=for-the-badge&logo=googlechrome&logoColor=white)](https://chromewebstore.google.com/detail/insta-harbor/ceemiopiofnidoljppkoonnjiibldlln)

![Insta Harbor product preview](Novo%20Projeto%20(1).png)

## Features

- Download individual photos and videos from the feed.
- Save Reels as video files.
- Download every item in carousel posts.
- Download available Stories.
- Download each Highlight separately.
- Download profile media in bulk.
- Organize files automatically by profile, Stories and Highlights.
- Interface designed to fit naturally into Instagram.

## Install

1. Open the [Insta Harbor listing](https://chromewebstore.google.com/detail/insta-harbor/ceemiopiofnidoljppkoonnjiibldlln).
2. Select **Add to Chrome**.
3. Open Instagram and sign in.
4. Use the download controls shown on supported media and profile pages.

## Privacy

Insta Harbor does not send downloaded photos, videos or Instagram passwords to its servers. Limited analytics and technical error reports are used to improve the extension. Read the full [Privacy Policy](https://insta-harbor-privacy-policy.pages.dev/).

## Responsible use

Only download content that you own or have permission to save. Insta Harbor is an independent extension and is not affiliated with, sponsored by or maintained by Instagram or Meta.
